### Core Infrastructure

* **Edge Request Routing:** Distributed routing layer with multi-region failover and provider abstraction.
* **Low-Latency Streaming:** Resilient Server-Sent Events (SSE) pipelines with dynamic buffer management.
* **Zero-Retention Boundaries:** Ephemeral transit protocols with no persistent user payload retention.
* **Identity & Quotas:** Per-identity rate limiting and adaptive capacity throttling.
